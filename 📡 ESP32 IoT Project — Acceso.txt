https://github.com/Tomyr02/esp32-mcp-server

🔥 Firebase Realtime Database:
https://esp32aws-903f7-default-rtdb.firebaseio.com/sensores.json

🛠️ Para conectar en VS Code con Copilot:
1. Crear cuenta en horizon.prefect.io
2. Generar API Key en Settings → API Keys  
3. Agregar en settings.json de VS Code:
{
  "mcp": {
    "servers": {
      "esp32-sensor": {
        "type": "sse",
        "url": "https://esp32-sensor-server.fastmcp.app/mcp",
        "headers": {
          "Authorization": "Bearer <su-api-key>"
        }
      }
    }
  }
}
